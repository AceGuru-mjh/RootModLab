ℹ️ 关于 HideAllRoot v2.0

版本
v2.0 (versionCode 10)
作者
RootModLab
引擎
VFS 卸载 + PLT Hook 双引擎
兼容
Magisk 25+ / KSU+ZN / APatch+ZN
HideAllRoot 通过 Zygisk 在应用进程内重写底层 libc 调用与直接 syscall， 覆盖文件访问、属性、进程枚举、maps、挂载点、守护进程 socket、环境变量、 SELinux context 与反调试等维度，对抗 Momo / Ruru / 春秋(SpringRoot) / RootBeer / Play Integrity 检测。所有行为由 /data/adb/hideallroot/config.conf 驱动，可经本面板即时调整。

⚠️ 合规与免责

本项目为开源安全研究工具，遵循 Magisk 通用模块规范。请仅在你拥有或获授权的设备上使用， 遵守所在地区法律法规。模块不修改系统分区、不植入后门，深度隐藏均在应用进程命名空间内完成。
